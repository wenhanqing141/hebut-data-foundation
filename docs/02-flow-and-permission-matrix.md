# 流程与权限矩阵

## 1. 主业务链路

```text
创建基础数据表
  -> 配置分类和表单字段
  -> 启用基础数据表
  -> 自动生成增删改查接口
  -> 注册应用
  -> 关联业务表
  -> 配置基础表/公共服务/其他应用接口授权
  -> 应用按授权调用或通过表单联动使用
  -> 记录访问、数据变更和授权日志
  -> 管理员查询和审计
```

## 2. 角色矩阵（第一版）

| 角色 | 基础表管理 | 前台数据维护 | 应用管理 | 授权配置 | 日志审计 |
|---|---|---|---|---|---|
| 基础数据管理员 | 创建/修改/删除/启停/分类 | 视业务需要 | 可选 | 可选 | 可选 |
| 接入管理员 | 只读或无 | 无 | 注册/接口/关联业务表 | 配置 | 可选 |
| 业务人员 | 无 | 按角色查看和维护 | 无 | 无 | 无 |
| 审计人员 | 无 | 无 | 只读 | 只读 | 查询/查看详情 |

说明：PRD 没有给出最终角色名称和管理员之间的细分权限，上表用于设计阶段占位，不可直接视为最终权限配置。

## 3. 授权判定规则

### 3.1 读数据

```text
实际可读数据
= 表单/跨表联动自身过滤条件
  ∩ 应用对基础表的查询过滤条件
  ∩ 字段可见权限
```

没有数据交集时，页面显示无可读数据，不应泄露被过滤数据的数量或内容。

### 3.2 写数据

```text
执行成功条件
= 应用拥有对应动作权限
  ∩ 数据满足对应过滤条件
  ∩ 请求字段拥有字段编辑权限
```

无权限时执行失败并写入日志。部分字段可编辑、过滤条件不满足、动作权限缺失时的错误提示需要产品确认最终文案。

### 3.3 基础表生命周期

```text
新建 -> 停用 -> 启用 -> 停用 -> 删除
```

- 新建默认停用。
- 启用后生成接口。
- 停用后接口立即失效。
- 删除前要求输入完整表名确认。
- 删除后清除数据、字段配置、接口和授权关系，并恢复初始化状态。
