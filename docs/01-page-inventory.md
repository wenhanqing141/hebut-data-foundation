产品提供的五份 HTML 是需求参考和状态拆分，不等于最终文件数量。

## 2. 基础数据中心后台（最终交付 HTML 之一）

### 2.1 初始化状态

- 左侧展示默认的“基础数据表”分类。
- 支持新建同级分类、新建子级分类、排序。
- 右侧显示“暂无基础表”空状态。
- 主操作为“创建基础表”。
- 未创建基础表时，权限设置为禁用态。

### 2.2 已创建状态

- 左侧展示数据分类和基础数据表树。
- 右侧展示数据表标题、启用/停用、修改表单、删除表单。
- 数据区域提供新增、导入、导出、删除、复制、批量编辑、通过、不通过等操作。
- 提供筛选条件、表格、分页/排序和行级查看、编辑、删除。
- 权限设置按角色配置前台可见的分类和基础数据表。

### 2.3 关键弹窗

- 权限设置：角色选择、分类/表单树勾选、保存后立即生效。
- 选择角色：按组织分组，支持搜索和多选。
- 启用：说明会生成增删改查数据接口，并对其他应用开放。
- 停用：说明接口立即失效，可重新启用。
- 删除：说明不可恢复，要求输入完整基础数据表名称确认。

初始化状态和已创建状态必须在同一个后台 HTML 中通过数据状态、路由参数或原型交互切换，不再拆成两个最终文件。

## 3. 基础数据中心前台（最终交付 HTML 之二）

- 顶部导航进入“基础数据中心”。
- 左侧仅展示当前用户角色有权限的分类和基础数据表。
- 右侧展示数据表数据。
- 支持新增、导入、导出、删除、复制、批量编辑、审核类操作，具体可用性由权限决定。
- 前台页面不负责配置基础数据表结构和应用授权。

## 4. 接入中心（最终交付 HTML 之三）

应用管理和日志管理属于同一个接入中心 HTML，共享同一套顶部导航、左侧导航和页面布局。左侧导航至少包含“应用管理”和“日志管理”两个分组或入口。

### 4.1 注册与授权

- 支持按应用名称、appid、负责人筛选。
- 支持应用注册、查看/修改应用详情、删除记录。
- 应用注册包含名称、负责人、联系方式、是否对外提供接口、简介等字段。
- 保存后生成 appid 和 appkey；复制应用信息时只能复制数据库中已保存的值。
- 应用可进入接口明细、关联业务表和配置数据权限。

### 4.2 接口管理

- 展示应用对外提供的接口。
- 支持启用、停用、修改和删除接口。
- 支持新增接口和接口文档入口。
- 需要明确接口状态、方法、路径、字段参数、鉴权方式和错误反馈的最终规则。

### 4.3 关联业务表

- 一个应用可以绑定多个业务表。
- 一个业务表只能绑定一个应用。
- 支持未关联/已关联快捷筛选。
- 已绑定其他应用的业务表不可被当前应用再次管理。
- 关联关系决定业务表-appid-授权服务的对应关系。

### 4.4 配置数据权限

- 可授权对象包括启用中的基础数据表、数据基座公共服务、其他应用提供的接口。
- 基础数据表权限至少包含查询、新增、修改、删除等操作。
- 每个操作可设置数据过滤条件。
- 支持字段可见、字段可编辑配置。
- 敏感字段需要明确可见性和脱敏规则的边界。
- 公共服务一期支持通知/发通知。

### 4.5 授权视图

- PRD 要求按应用视图和基础表视图展示。
- 支持按应用和授权对象下拉搜索。
- 基础数据表服务支持查看操作数据权限和字段权限详情。

## 5. 日志管理

- 基础数据日志：记录谁、何时、以什么身份、通过什么应用访问或修改哪张基础数据表、哪些字段及结果。
- 数据表日志：记录字段、配置、索引等数据表结构变化。
- 授权日志：记录应用注册、数据权限、公共服务、取消授权等变化。
- 日志列表支持时间、人员、类型、对象等条件筛选。
- 基础数据日志支持打开操作详情，并查看涉及的数据记录及记录级日志。
