# 数据基座 2.0 需求与原型基线

## 1. 文档用途

本文件是 UI 设计和 HTML 原型实现的第一版输入基线。它只整理用户提供的 PRD 和五个原型 HTML，不把原型中的脚本注释、示例数据或临时交互当作新增需求。

需求优先级约定：

1. 已确认的 PRD 业务规则；
2. PRD 中明确的本期范围和结论；
3. 原型中已经表现且不与 PRD 冲突的页面结构和交互；
4. 原型中的视觉样式、示例数据和未确认文案，仅作为待优化对象。

## 2. 资料来源

- PRD：飞书文档《河北工业大学_数据基座2.0》，读取时间：2026-10-21。
- 原型：`基础数据中心后台-初始化.html`。
- 原型：`基础数据中心后台.html`。
- 原型：`基础数据中心前台.html`。
- 原型：`接入中心 - 应用管理.html`。
- 原型：`接入中心 - 日志管理.html`。

最终交付不是五份 HTML，而是三份 HTML：

1. 基础数据中心后台：合并初始化状态和已创建后的完整管理状态；
2. 基础数据中心前台：业务人员使用基础数据的页面；
3. 接入中心：合并应用管理和日志管理，使用同一套顶部导航和左侧导航。

## 3. 项目基本信息

- 产品负责人：魏芳。
- 优先级：紧急。
- 期望上线时间：2026.11。
- 需求范围：PC 端。
- 项目目标：统一建表、统一授权、统一调用、统一日志、统一运营。
- 产品方向：先服务河北工业大学，再沉淀为可配置、可复制的标准产品。

## 4. 已确认的产品目标

- 基础数据表与表单/审批业务数据逻辑隔离。
- 基础数据表的 API 调用和跨表联动使用同一套授权规则。
- 授权从数据范围扩展到字段可见、字段可编辑。
- 基础数据表的创建、维护、启停、接口生成和授权配置集中管理。
- 统一记录基础数据访问、数据表配置和授权相关日志。
- 一期统一改造表单/审批引擎；其他引擎一期不允许选择基础数据表，二期再评估统一授权。

## 5. 当前明确不属于本轮页面范围的内容

- 移动端页面。
- 其他引擎一期接入基础数据表作为数据源或目标表。
- 触发器页面上的权限判断改造；PRD 结论是由后端判断，执行失败写入日志。
- 后端接口、鉴权、日志存储等真实服务实现。
